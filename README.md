## Featured projects

### [AI Interior Design App](https://github.com/mananaggarwal2001/AI-Interior-Design-App)
Upload a photo of a room and get AI-generated redesigns, with a before and after slider to compare them.
**Stack:** Next.js, React, Tailwind CSS, Clerk authentication, MongoDB (Mongoose), Replicate AI, Razorpay payments

### [PassOP Password Manager](https://github.com/mananaggarwal2001/Password-Manger)
A password manager for saving, editing and deleting site credentials. Built in two versions: one using browser local storage, and one with a backend API.
**Stack:** React, Tailwind CSS, Spring Boot

### [Spotify Clone](https://github.com/mananaggarwal2001/Spotify-Clone) · [Live demo](https://myspotifyclonesuper.freewebhostmost.com/)
A music player with a seek bar, volume control, next and previous track buttons, and albums that load their songs dynamically.
**Stack:** HTML, CSS, JavaScript

### [Coding Blocks Java DSA](https://github.com/mananaggarwal2001/CodingBlocksJavaDSALatest)
My solutions to the Coding Blocks Java DSA course, organised topic by topic: arrays, sorting, binary search, 2D arrays, strings and recursion.
